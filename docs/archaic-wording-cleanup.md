# 提示词写作与古风清理

本规范与原版「命定之诗」仓库保持同源一致，用于规范「任务助手（Quest Assistant）」世界书与模型提示词的写作和审校。提示词使用自然、清楚的现代汉语，保持西幻语境。

## 语体

提示词是写给模型的规则与设定说明，统一采用客观、中立的书面语。

1. 客观陈述：写事实、条件、动作和输出要求，不带作者的情绪、评价、玩笑或吐槽。
2. 中立视角：以旁述的第三人称描述角色与玩家，例如「<user>离开该区域后……」「在当前任务未接取时……」。规则正文里的玩家一律写 `<user>`，不用「玩家」「你」或角色对玩家的称呼（如「主人」）代替。
3. 规范书面：不用口语、网络用语和语气词，如「啦」「哦」「嘛」「白嫖」「刷好感」「一口气」「找乐子」「吃掉点击」。需要表达角色态度时写清具体态度，例如「以撒娇的语气说明无法出发」，不写成「撒娇说去不成」。
4. 规则写成「条件 → 动作 → 输出」：说明什么情况下、由谁、做什么、输出什么格式；数值、上限和例外写明。
5. 保留角色口吻的地方：角色台词、示例对白、开场白、角色心声，以及描述说话风格时引用的原句。这些内容按角色口吻书写，不受上面几条限制，玩家称呼也按角色习惯写。
6. 角色设定（性格、喜好、行为习惯）用中性的描述性语言陈述，不模仿角色本人的语气。

## 改写规则

1. 文言虚词按语境换成白话：`于` → `在/从`，`其` → `它的/他们的`，`皆` → `都`，`亦` → `也`，`乃` → `是`，`均可` → `都可以`；`位于`、`建于`、`死于`、`其中` 等现代常用搭配保留。
2. `X 掌 Y` 改为 `X 负责 Y`；`此岭`、`一峰`、`设于此峰` 等山水腔改为 `这座山岭`、`一座山峰`。
3. 只拆文言味的四字格（如 `月夜尤澈`、`循山道`），信息型短语（如 `政治中立，平等自由`）保留。
4. 距离用米/公里，时间点用 `时刻`，时长用小时等单位，按设定换算并保留原意；晨昏可写清晨和黄昏/早晚。
5. 专名默认保留；涉及存档变量路径或协议字段名时严格保持向后兼容，不随意改键名。
6. 本来就是东方设定的内容不动：蝾螈王朝与天镜湖湿地、东方龙裔、千爻、龙娘傲雪、读者核心的汉服/旗袍形态。
7. 「凡人」可用于与神灵、不朽生命的对照，也可保留在角色口吻或明确的东方文化中；描述具体种族、普通居民或实力时按实际含义用词。
8. 超凡力量由虚海源能（简称「源能」）在位面内依当地法则转化而来；各体系按角色、族群和传承划定范围，以技能呈现。禁止使用「血气」「斗气」「以太」称呼；非东方设定禁用古风、武侠、修仙类称呼。

## 日常写作与审校

检查完整段落里的修仙话术、半文言句式和成串的山水腔，结合下方保留项判断。

西幻中文可采用译作中略正式、具体的叙述。设施、机构按用途和文化背景自然命名，句子写清行动主体；宗教与工艺描写保留设定依据，避免用雅字重新拼出宗门式名称。改写示例：

| 原写法 | 建议写法或判断 |
| --- | --- |
| 生命层级突破到了…… | 生命层级晋升到了……；「突破封锁」是正常用法 |
| 此地由议会掌商贸，亦管税赋 | 这里的商贸和税收都由议会负责 |
| 贵族角色使用古风措辞 | 贵族角色使用古典贵族式措辞，再写清礼仪、态度和说话习惯 |
| 金穗承阳，无惧凛冬 | 势力格言文体，按现有设计保留 |
| 淬霜池 | 冰泉淬火池，直接交代水源与工艺用途 |
| 净尘居：住所负责净化仪礼 | 工坊宿舍；住在里面的工匠负责净化仪式与日常维护 |
| 能量（魔力/血气）凝练 | 超凡力量的承载、运用与生命跃迁，具体表现由角色与技能决定 |

### 精简提示词

- 合并同一轮上下文里含义相同的提醒；独立激活条目保留各自需要的说明，以及不同的条件、对象和例外。
- 把「必须、务必、再次强调」的堆叠改成一条具体要求，写清条件、动作和输出即可。
- 防错要求以实际约束或已知问题为依据，删去没有具体作用的兜底、自查和确认步骤；保留实际生效条件、输出格式和变量写入要求。

AI 助手使用 [prompt-style](../.agents/skills/prompt-style/SKILL.md)，例如：「按 prompt-style 检查本次提示词改动。」

## 本仓库专用术语与保留项

- 任务系统固定键名与分类名：`任务情报板`、`剧情任务`、`本地主线`、`支线任务`、`余波`、`区域访问日`、`上次重扫日`、`已完成`、`已兑现`、`已失效`、`已忽略`、`已锁定`、`真相`、`任务列表`。
- 词条格式标签：`[绿]`、`[黄]`、`[红]`、`[至YYYY年-M月-D日]`、`【短标签】`。
- 机制术语：`命运点数` / `FP`、`null核心`、`事件链`、`MVU`、`UpdateVariable`。
- 正常现代搭配（如 `处于`、`属于`、`基于`、`位于`、`其中`、`与其……不如……` 等）按常规现代汉语保留，不做机械替换。
