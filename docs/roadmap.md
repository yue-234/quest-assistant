# 后续功能规划与设计备忘

本文档用于沉淀暂未进入编码排期的玩法构想与技术边界分析，供后续版本（`v1.4.14` 及以后）立项与实现参考。

---

## 1. `【多方竞速】` 短计时器与信息隔绝「延迟愕然」演化

### 目标体验
解决当前 `【多方竞速】` 缺乏“对手也在同步抢先行动”紧迫感，以及演进消息容易流于全知视角的两大问题：
- **节奏对味**：将已接取的竞速任务从长线 5 天拖延周期缩短为贴合竞速节奏的短周期，让拖延真正产生成本。
- **有限视角与愕然感**：主角不在现场时，竞争对手暗中抢先动作；回到人群或酒馆时才从侧面闲谈撞见风声，并于同一瞬间在面板同步落定折损代价。

### 构想方案
1. **分骨架短计时器（仅限已接取）**
   - 未接取任务继续保持状态冻结，避免玩家未曾关注的本地委派静默过期。
   - 普通 `剧情任务` 保留默认 5 天演进周期；已接取且带 `【多方竞速】` 的任务（含 `剧情任务` 与 `本地主线`）缩短为 **1~2 天**起步触发演进。
   - `本地主线` 总计仅 5 栏 `预期收益`，短周期演进建议按**每次 1 栏**细步折损（而非剧情任务 10 栏下的每次 2 栏），防止跨夜一两天即崩溃。
   - 若同时叠加 `【假象余震】` 一阶段，需控制初期折损步幅与容错，保留顺利结案种下 `余震引信` 的合理空间。
2. **「环境侧面透风声」补偿机制（禁止先知与队友机械报点）**
   - 对手真实推进仅记入隐藏的 `真相`，不直接以全知视角写进玩家可见的 `/任务列表/<任务名>/进展`。
   - 失去的 1 栏收益作为「先机代价」，换取一次受当前环境严格约束的侧面风声线索：
     - **城镇 / 酒馆 / 集市 / 学院**：借邻桌吹牛闲谈、商贩抱怨行市变动、公告栏或订货异动等半截传闻透出危机征兆（不直接报出精确坐标与完整经过）。
     - **禁止先知报点**：明确禁止一直与主角同行的队友或随从在无外界情报来源时突然精准告知“对手去了某码头准备跑路”。
3. **信息隔绝下的「连 `[✕]` 都藏着」与延迟揭晓**
   - 当演进触发时若 `<user>` 正处于荒野、地牢、密室等无外界信息流环境：
     - 正文不强行刷出传闻或信使。
     - 后台悄悄推进隐藏 `真相` 与已错失栏位，并将该栏位与待传达风声**暂存于隐藏控制字段**，**暂不写入公开的 `/事件/任务情报板/已失效`**，也不改写可见 `进展`（面板上暂不提前亮红叉）。
     - 在后台独立记录演化日期（例如 `最近演化日`），与可见 `进展` 的日期戳解耦——防止因隔绝轮未更新 `进展` 日期导致下一回合连续重复扣栏位。
   - 待 `<user>` 重返城镇、酒馆、驿站或遭遇商旅/邮差时，`plot` 借环境旁白自然放出风声，同一轮 `update` 将暂存栏位正式转写进 `已失效` 并刷新玩家可见 `进展`，形成听感与面板红叉同步揭晓的错愕体验。

## 2. `<user>` 第一视角「任务日记」（冒险手账）

### 目标体验
将任务完成后的记录从纯客观的进度档案，扩展为可逐页翻阅的**第一人称个人手账**，沉淀角色在冒险途中的情绪、见闻与伏笔体感。

### 构想方案
1. **内容定位：个人视角、经历与心境**
   - 严格以 `<user>` 第一人称与当前人设口吻撰写，记录经历细节、狼狈或得意瞬间、对委托人/同伴的私下评价、隐约觉察却未深究的异样等。
   - 禁止复述任务 `摘要` 或客观战报，与现有的 `/任务列表/<任务名>/进展` 明确分工。
   - 若某条任务在数十轮后触发 `【假象余震二段】` 或跨期后续，可在同篇日记下自动续写「后续篇」，让玩家翻阅时形成前后呼应。
2. **生成时机：关键节点 / 完结归档**
   - 避免每回合琐碎追加造成流水账与体积膨胀。
   - 推荐结合「关键节点摘录」与「完结成篇总结」：在结案（正常完成、折损止损或失败）或遭遇重大转折时凝练生成该任务的手账页，并归档保存，支持在前端做成按页/书签切换的独立手账界面。
3. **上下文与存储约束（防膨胀红线）**
   - **跟随楼层状态**：日记正文归档于 MVU 隐藏节点（例如独立的日记归档字段），确保酒馆删楼、重 Roll 或导出存档时能严格同步回溯，不会出现剧透未来的状态错位。
   - **禁止回喂历史正文**：世界书提示词仅在当轮任务完结或跨节点需新写/续写时输出当前篇幅；**已归档的历史日记绝不注入后续对话的模型上下文**，完全专供前端渲染阅读，避免长档 Token 暴涨或触发预设总结正则上限问题。

## 3. 前端「冒险手账」UI 重构构想

### 目标体验
配合第一视角「任务日记」与城邦风物记录，将现行悬浮徽章与现代暗色卡片弹窗演进为兼具仪式感与操作效率的拟物手账体系，保持零外部图片依赖，并在结构与视觉语言上实现完全原创。

### 构想方案
1. **牛皮书悬浮入口与中轴展开动效**
   - **牛皮书悬浮按钮**：使用内联 SVG 与 CSS 绘制微缩立式牛皮手账——左缘带缝线书脊、右缘露微米黄书页厚度、正中镶嵌现行标识延续的黄铜指南针星芒扣，顶/右上角露出一截可指示未读更新或新日记的丝带书签。
   - **书脊对开动效**：点击悬浮图标后，面板中心先浮现闭合封面，再以书脊为中轴向两侧对半展开（约 `280ms~320ms` 缓动）；动画结束直接落在可交互页，**不额外增加拦截点击的封面扉页**，同时兼容 `prefers-reduced-motion` 与设置项内的动画开关。
2. **PC 端「双页冒险手账」（功能分治原创布局）**
   - **原创材质与配色**：深胡桃/棕褐皮质外封配黄铜包角，内页采用暖米羊皮手账纸质感（不使用普通横线信纸），保留青金与琥珀金作为火漆印章及高频操作按钮点缀，形成与单功能回忆录页面完全区隔的视觉识别。
   - **硬卡书签页签分页**（`委托板` / `风物志` / `冒险日记` / `设置`）：
     - **委托板**：左页展示当前区域、世界日、重扫火漆按钮、关注方向贴条与分类任务列表（保留快捷锁定与忽略）；右页随选中任务实时展开委托线索、地点/时限纸条、公开摘要、`预期收益` 印章勾选栏（`[✓]`/`[✕]`/`[□]`）及关联日记跳转折角。
     - **风物志**：左页展示本区常驻词条与限时活动便签（以绿/黄/红墨水圆章区隔）；右页以剪贴报刊块展示跨区与世界级重大余波。
     - **冒险日记**：左页为按城市与结案时间归档的目录索引（附心情/结局戳印）；右页呈第一人称日记正文与边栏手写角注，支持逐篇翻页重温。
3. **手机端「随身便签本」（Pocket Pad）**
   - 小屏不强行缩放双页排版，改为竖版顶边带装订环或牛皮束带的随身便签本形态，以折耳页签切换 `委托` / `风物` / `日记`。
   - 单条任务采用可就地手风琴展开或抽拉的便签纸条卡片，单手拇指即可完成核查与收益印章切换；日记页按单页卡片逐张切换翻阅。

### 工程实现边界
- **内容区占比护栏**：严格收敛皮质外框与装订边宽度，确保 PC 与移动端（含酒馆 `iframe` 小视口）有效内容阅读面积不低于 `85%`。
- **离线自洽打包**：所有皮革纹理、星芒扣与火漆图标均采用内联 SVG 与 CSS 渐变实现，确保单文件产物保持轻量且零外链失效风险。

## 4. 结案与失败任务回执暂留（先看后删）

### 目标体验
解决任务在完结或竞速失败后同一回合即从 `/任务列表` 与 `/事件/任务情报板/列表` 清除导致“玩家点开面板却发现任务凭空消失、误以为丢失或出现 Bug”的体验断层——尤其配合「`【多方竞速】` 回城撞见风声再揭晓 `[✕]`」时，确保玩家打开前端能够亲眼看到明确的结局反馈，阅读后再清理。

### 构想方案
1. **现役列表照常结清 + 前端截获结案快照**
   - 不将已结束任务硬留在 `/事件/任务情报板/列表` 中占用配额或阻塞 `导演状态` 引信提取（`updateDirectorAfterSweep`）与剧情任务补足。
   - 改为在任务离板时生成轻量「待阅结案回执」（记录标题、类别、等级、终局状态如 `✓ 已完成` / `✓ 折损结案` / `✕ 已失败` / `✕ 已放弃`、最后一条进展/传闻原因及各栏 `[✓]`/`[✕]` 结算情况），覆盖两条产生路径：
     - **途径 A**：`sweepClosedQuests` 自动清扫残留时顺手拍照转存回执；
     - **途径 B**：AI 当回合直接执行 `remove` 移出 `列表` 时，前端比对 `historyStats` 上一楼层快照，识别本轮刚消失的条目并结合 `/任务列表` 与 `已兑现`/`已失效` 状态补齐回执，防止漏单。
2. **零 AI 上下文损耗的暂存展示期**
   - 待阅回执仅作为前端展示状态留存，**世界书提示词不读取、不注入给 AI**（0 Token 开销，不干扰下轮生成与配额）。
   - 玩家尚未点开前端面板查看前，回执卡片始终带对应颜色火漆戳印保留在面板中，并保持悬浮入口未读红点提示。
3. **点开展示、下回合清理的闭环与回溯一致性**
   - 玩家打开面板查阅该回执时**不当场闪没**，允许同回合反复开关核对结果，仅标记 `已阅 = true`（及查看时的消息楼层）。
   - 待**下一回合新消息推进剧情**（或玩家手动点击收起/归档按钮）时，由后台静默将该回执移出待阅区；若已启用「任务日记」，则顺势衔接归档成手账正文。
   - 状态按楼层一致性维护：若玩家在该回合触发重 Roll（`swipe`）或删楼回退，回执与未读状态同步还原，不留存平行时空假回执。

## 5. 推荐实施顺序

为避免在旧暗色列表 UI 上重复编写并废弃一套临时卡片样式与状态耦合，后续建议按两步推进：
1. **第一步（重构纯前端 UI）**：基于现行稳定的 `v1.4.13` 变量结构，先行落地「牛皮书悬浮入口 + 展开动画 + PC 双页手账 / 手机随身便签本」，并预留 `冒险日记` 页签与回执展示插槽。
2. **第二步（集中接入玩法与后端规则）**：在新前端架子上一次性打通「结案与失败回执暂留」「`【多方竞速】` 短计时与藏 `[✕]` 延迟吐露」及「`<user>` 第一视角任务日记」，前后数据流与视觉呈现一次成型，减少返工。
