# 任务助手（Quest Assistant）

项目地址：<https://github.com/yue-234/quest-assistant>

面向「命定之诗与黄昏之歌」的独立通用任务情报板插件，不依赖任何特定命定核心。通过独立悬浮球打开单页任务面板，配合世界书 EJS 实现区域任务自动生成、进度联动与完结自动清理。

## 核心特性

- **通用适配**：独立使用变量路径 `/事件/任务情报板`，不绑定特定核心，不覆盖任何核心 `setvar` 宏；普通核心下重扫本地情报沿用通用 `100 FP`，启用 **`null核心`** 时自动切换为**每日 1 次免费重扫**（1 游戏日 CD）。
- **区域动态任务板**：按所在城镇/大区域自动维护「剧情任务 / 本地主线 / 支线任务」三类情报，优先承接上下文已激活的世界书事件/事件链（兼容原版与创意工坊自制），支持锁定、忽略与主动重扫。
- **剧情 NPC 动态上墙 & 原版任务打通**：剧情中路过 NPC 给出的新委托或自然触发的原版 `/任务列表` 任务不受默认数量限制，可直接动态上墙；未上墙的进行中原版任务也会在前端自动只读聚合展示（带「剧情同步」徽章）。
- **当前区域 / 世界区域词条**：采用三色阶 `[绿/黄/红]【短标签】客观现状` 格式（翡翠绿利好 / 琥珀黄隐患 / 绯红危机，兼容旧无色词条）持久化在 `/事件/任务情报板/余波`（单区域与「世界」各自最多保留 3 条），并记录 `/事件/任务情报板/区域访问日`。首次进入新区域时默认生成 3 条差异化色阶的初始区域词条（禁止纯色，也不机械套用 1 绿 1 黄 1 红）；「世界」词条不默认生成、仅剧情任务跨大区或全大陆级重大后果写入；剧情任务与本地主线产生实质后果时动态改写词条；返回旧区域离开满 14 天可根据剧情与局势演进 1 条词条，不足 14 天保持稳定（期间有明确剧情变故、到期预告事件或任务后果波及时仍按剧情改写）。世界书仅在对应区域注入本区词条（异区 0 token 注入），面板顶部以独立双栏三色微光卡片展示。
- **单源联动与防草率结案**：未接取任务只写任务板，接取后只更新正式 `/任务列表/<任务名>`；主线/剧情任务内置后台隐藏「真相」，顺应任意调查顺序。
- **多栏预期收益与修改模式**：实时展示多栏预期收益并随剧情自动打 `✓`，开启「修改模式」可手动校准已兑现收益，或对区域/世界词条执行行内二次确认删除。
- **三重完结兜底清理**：结合「已兑现记录」「曾接取持久化印记」与「历史楼层 `stat_data.任务列表` 反查」，并配合后台安静时机自动清理，避免任务完结后残留或回退为未接取。
- **独立弱磁吸悬浮球**：60×48 深空蓝金边徽章，支持自由拖拽停靠（仅极近左右边缘 `≤ 28px` 轻吸附）、按比例记忆位置、未读剧情进展红点提示与后台休眠省电。

## 兼容性说明

- **变量更新方式**：仅支持主 API 随 AI 输出更新变量（`<UpdateVariable>`），**暂不支持「使用额外模型更新变量」模式**。
- **与 UNN 演播室核心的关系**：启用 UNN 演播室核心时**请勿与本独立任务助手同时开启**（两者各自包含任务板世界书提示词，同开会导致两套任务板提示词冲突）。
- **`null核心` 适配**：在 `null核心` 下自动免除 `100 FP` 消耗，改为每日 1 次免费重扫（按游戏世界日计算 1 天 CD）。

## 快速安装（SillyTavern）

1. **安装前端脚本**：复制 [`⭐粘这个-任务助手脚本.js`](./⭐粘这个-任务助手脚本.js) 的全部内容，在酒馆脚本助手（TavernHelper）中新建脚本粘贴并启用。
2. **安装世界书条目**：复制 [`任务助手-世界书.ejs`](./任务助手-世界书.ejs) 的全部内容，在当前使用的世界书中新建常驻（蓝灯）条目粘贴并启用。

详细使用说明见 [`使用说明.md`](./使用说明.md)。

## 目录结构

```text
├── ⭐粘这个-任务助手脚本.js   # 构建好的零依赖单文件脚本（直接粘贴使用）
├── 任务助手-世界书.ejs        # 独立通用世界书提示词（直接粘贴使用）
├── 使用说明.md                # 安装与日常使用说明
├── build.mjs                  # esbuild 打包脚本
├── test.mjs                   # Node 原生单元测试
└── src/                       # 前端与逻辑源码
    ├── data.js                # 任务板基础配置（档位、栏位与重扫参数）
    ├── state.js               # 区域识别、去后缀匹配、历史楼层反查与完结判定
    ├── actions.js             # 锁定、忽略、100 FP 重扫、打勾与清扫动作
    ├── host.js / commit.js    # 宿主变量读写与 MVU 提交封装
    ├── panel.js / panel.css   # 单页任务情报面板界面与样式
    ├── fab.js                 # 可拖拽弱磁吸悬浮球
    └── runtime.js             # 入口挂载与后台静默维护
```
