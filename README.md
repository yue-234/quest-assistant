# 任务助手（Quest Assistant · 冒险手记）

项目地址：<https://github.com/yue-234/quest-assistant>

面向「命定之诗与黄昏之歌」的独立通用任务情报板插件，不依赖任何特定命定核心。通过立体牛皮手记悬浮入口打开**冒险手记**（桌面端硬壳双页手记 / 手机端随身便签本），配合世界书 EJS 实现区域任务生成、多方竞速短计时演化、结案回执暂留、第一人称冒险日记与完结自动清理。

## 核心特性

- **通用适配**：独立使用变量路径 `/事件/任务情报板`，不绑定特定核心，不覆盖任何核心 `setvar` 宏；普通核心下重扫本地情报沿用通用 `100 FP`，启用 **`null核心`** 时自动切换为**每日 1 次免费重扫**（1 游戏日 CD）。
- **冒险手记交互界面（`委托板` / `风物志` / `冒险日记` / `⚙ 设置`）**：
  - **桌面端双页手记 & 手机端随身便签本**：PC 端采用胡桃棕皮质外封、黄铜包角与暖米羊皮纸张双页排版（点击悬浮入口播放中轴展开动画）；小屏竖屏自动切换为顶边装订环随身便签本，短横屏压缩为单行轻量顶栏，保证高阅读占比与拇指直达操作。
  - **动效开关**：支持系统减动效偏好及设置页一键切换「完整翻页动效 / 零动效瞬开」。
- **区域动态任务板与四大骨架轮换**：按所在城镇/大区域自动维护「剧情任务 / 本地主线 / 支线任务」三类情报，优先承接上下文已激活的世界书事件/事件链（兼容原版与创意工坊自制），并在剧情/本地主线中轮换 `【悬疑反转】`/`【多方竞速】`/`【灾变探索】`/`【护送破局】` 四大骨架与 `【假象余震】` 二段伏笔闭环。
- **`【多方竞速】` 短计时与信息隔绝延迟揭晓**：已接取的竞速任务缩短为 1 日快节奏演进。在城镇、酒馆或人群环境中借半截传闻透风声并同步落定折损；当 `<user>` 处于荒野、地牢、密室等隔绝环境时正文保持留白，后台将风声与 `[✕]` 栏位暂存至 `竞速暂存`，待重返人群场所后再集中吐露风声并同步划出红叉（同日不双扣，隔绝轮禁止偷看变量漏风声）。
- **待阅结案回执（先看后删）**：无论后台清扫残留还是 AI 当回合直接移出面板，均自动捕获离板任务的「待阅结案回执」（标注 `✓ 已完成` / `✓ 折损结案` / `✕ 已失败` / `✕ 已放弃` 及各栏结算结果）并点亮未读红点；玩家点开手记后当回合保留，支持手动「收起」或待下一 AI 回合落地再自动清理，避免任务结果凭空消失。
- **第一视角 `冒险日记`（`任务日记`）**：重大任务结案同轮由主模型以 `<user>` 第一人称与当前角色口吻静默写入个人手记（`【假象余震二段】` 等续作支持关联续写 `续篇`），历史日记正文零回喂世界书上下文，专供前端翻页阅读与角注回顾。
- **剧情 NPC 动态上墙 & 原版任务打通**：剧情中路过 NPC 给出的新委托或自然触发的原版 `/任务列表` 任务不受默认数量限制，可直接动态上墙；未上墙的进行中原版任务也会在前端自动只读聚合展示（带「剧情同步」徽章）。
- **当前区域 / 世界区域词条（含限时 Buff 词条）**：采用三色阶 `[绿/黄/红]【短标签】客观现状` 格式（翡翠绿利好 / 琥珀黄隐患 / 绯红危机，兼容旧无色词条）持久化在 `/事件/任务情报板/余波`（单区域与「世界」各自最多保留 3 条常驻词条），并支持以 `[绿/黄/红][至YYYY年-M月-D日]【短标签】客观现状` 写入**限时 Buff 词条**（不占用常驻名额，每区与「世界」各自最多额外叠加 2 条），同时记录 `/事件/任务情报板/区域访问日`。首次进入新区域时先于任务生成 3 条差异化色阶的初始区域词条（禁止纯色，也不机械套用 1 绿 1 黄 1 红）；「世界」词条不默认生成、仅剧情任务或重大剧情与事件链跨大区/全大陆级后果写入；返回旧区域离开满 14 天可根据剧情与局势演进 1 条词条，不足 14 天保持稳定（期间有明确剧情变故、到期预告事件或任务后果波及时仍按剧情改写）。世界书仅在对应区域注入有效词条（异区与过期词条 0 token 注入），在「风物志」页及顶部折叠卡片展示限时倒计时，并在跨天/跨城后后台自动清理全地图已过期限时词条。
- **多栏预期收益与三态修改模式**：实时展示高价值在前排布的多栏预期收益，随剧情自动打 `✓`（已兑现）或 `✕`（失败/恶化折损已失效）；开启「修改模式」可点击收益在「待获得 / 已兑现 ✓ / 已失效 ✕」间三态切换，或对区域/世界词条执行行内二次确认删除。
- **牛皮手记悬浮入口 / 魔法棒双入口切换**：默认显示纯 CSS + SVG 绘制的微缩牛皮手记悬浮入口（带缝线书脊、指南针星芒扣与摆动发光未读丝带书签，支持自由拖拽停靠与极近左右边缘 `≤ 28px` 轻吸附）；可在设置页切换为「魔法棒（扩展程序）」模式，隐藏悬浮手记并收入左下角 `#extensionsMenu` 扩展菜单。

## 兼容性说明

- **变量更新方式**：仅支持**「主 API 随 AI 输出更新变量（`<UpdateVariable>`）」**在主回复生成阶段直接更新 `/事件/任务情报板`（不再支持 MVU「额外模型更新变量」）。官方世界书交付包拆分为双 `[mvu_plot]` 子条目（`[mvu_plot]任务助手-剧情引导` + `[mvu_plot]任务助手-变量更新`），在保持剧情引导与变量更新规则前后分段注入的前提下，规避部分预设总结模块处理 `[mvu_update]` 条目时的正则表达式长度溢出问题。若仍启用带有 `[mvu_update]` 前缀的旧版世界书，设置页会弹出迁移提示。
- **与 UNN 演播室核心的关系**：启用 UNN 演播室核心时**请勿与本独立任务助手同时开启**（两者各自包含任务板世界书提示词，同开会导致两套任务板提示词冲突）。
- **`null核心` 适配**：在 `null核心` 下自动免除 `100 FP` 消耗，改为每日 1 次免费重扫（按游戏世界日计算 1 天 CD）。

## 快速安装（SillyTavern）

1. **安装前端脚本（三选一）**：
   - **方式 A · 远程自动更新版（推荐）**：复制 [`⭐粘这个-远程自动更新脚本.js`](./⭐粘这个-远程自动更新脚本.js) 的全部内容，在酒馆脚本助手（TavernHelper）中新建脚本粘贴并启用。默认跟随 `main` 最新构建（推送清缓存后自动同步，按 `testingcf` / `cdn` / `fastly` / `gcore` 四个 jsDelivr 节点自动回退），也可在设置页中随时切换并固定为老版本（如 `v1.4.13`）。
   - **方式 B · 单行 `import` 直链版**：在酒馆脚本助手中写入下面一行（使用 `@main` 追新，或改成 `@v2.0.0` 等 Tag 固定版本；进入设置页可查看实时最新版本号并手动输入切换热重载）：
     ```js
     import 'https://testingcf.jsdelivr.net/gh/yue-234/quest-assistant@main/dist/quest-assistant.js'
     ```
     （也可将域名替换为 `cdn.jsdelivr.net`、`fastly.jsdelivr.net` 或 `gcore.jsdelivr.net`。）
   - **方式 C · 离线单文件版**：复制 [`⭐粘这个-任务助手脚本.js`](./⭐粘这个-任务助手脚本.js)（或 [`.txt`](./⭐粘这个-任务助手脚本.txt)）的全部内容粘贴并启用，不依赖外网访问。
2. **安装世界书条目（二选一）**：
   - **推荐（一键导入）**：在酒馆世界书面板直接导入 [`命定任务助手世界书v2.0.0.json`](./命定任务助手世界书v2.0.0.json)（内置 `[mvu_plot]任务助手-剧情引导v2.0.0` 与 `[mvu_plot]任务助手-变量更新v2.0.0` 两个 `[mvu_plot]` 子条目，同时启用可在设置界面自动核对版本匹配；**从旧版升级时请关闭或移除旧版单条目 `任务助手v1.4.x` / `v2.x.x` 或带 `[mvu_update]` 的旧双条目**）。
   - **手动粘贴单条目**：复制 [`任务助手-世界书.ejs`](./任务助手-世界书.ejs) 的全部内容，在当前使用的世界书中新建常驻（蓝灯）条目（名称建议填写 `任务助手v2.0.0`）粘贴并启用（适合传统单条目用法；一般推荐直接使用一键导入的双 `[mvu_plot]` 子条目 JSON）。

详细使用说明见 [`使用说明.md`](./使用说明.md)。

## 目录结构

```text
├── ⭐粘这个-任务助手脚本.js          # 构建好的零依赖单文件脚本（离线粘贴使用）
├── ⭐粘这个-任务助手脚本.txt         # 同内容文本副本（方便移动端复制）
├── ⭐粘这个-远程自动更新脚本.js      # jsDelivr 四节点自动回退与版本切换加载器
├── 命定任务助手世界书v2.0.0.json     # 打包好的双条目标准酒馆世界书（双 [mvu_plot] 子条目）
├── dist/quest-assistant.js           # jsDelivr CDN 分发用纯英文路径产物
├── 任务助手-世界书.ejs               # 独立通用世界书提示词（直接粘贴使用）
├── 使用说明.md                       # 安装与日常使用说明
├── build.mjs                         # esbuild 打包脚本
├── test.mjs                          # Node 原生单元测试
├── tools/purge-cdn.mjs               # 刷新 jsDelivr @main 缓存辅助脚本
└── src/                              # 前端与逻辑源码
    ├── data.js                       # 任务板基础配置（档位、栏位、重扫参数与基准版本）
    ├── state.js                      # 区域识别、去后缀匹配、日记/回执解析与完结判定
    ├── actions.js                    # 锁定、忽略、重扫、打勾、回执截获清理与清扫动作
    ├── host.js / commit.js           # 宿主变量读写、并发队列与 MVU 提交封装
    ├── panel.js / panelViews.js      # 冒险手记主控制器与回执/风物志/日记辅助视图
    ├── panel.css                     # 桌面双页手记与手机便携便签本样式
    ├── fab.js                        # 可拖拽弱磁吸立体牛皮手记悬浮入口
    ├── wand.js                       # 魔法棒扩展菜单（#extensionsMenu）入口挂载器
    ├── entryMode.js                  # 入口模式（悬浮框 / 魔法棒）读写与归一化
    ├── motionPref.js                 # 手记翻页动效偏好读写与归一化
    ├── scriptRef.js                  # 远程脚本版本号校验、持久化与可用 Tag 查询
    └── runtime.js                    # 入口挂载、实时切换与后台静默维护
```

## 二次开发与验证

```bash
# 重新打包单文件脚本与世界书 JSON
node build.mjs

# 运行全部单元测试
node --test test.mjs

# 发布新版本 Tag（例如 v2.0.0）供玩家切换
git tag v2.0.0 && git push origin v2.0.0

# 推送 main 后主动刷新 jsDelivr @main 缓存
node tools/purge-cdn.mjs
```
